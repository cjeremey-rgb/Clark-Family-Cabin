# Huckleberry Bucket — V13 Shared Pot Prototype

## Core rules
- One shared Huckleberry Bucket is in the middle.
- Numbered Huckleberry cards add their value to the shared pot.
- Twig, Leaf, and Bug cards stay face-up with the player. Three matching trouble cards bust that player out of the current bucket.
- Head Home offers 20 guaranteed berries. Take them and leave the current bucket, or decline and stay in for the full pot.
- Last active picker wins the shared bucket.
- Evie is saved. Each Evie held by another player removes 10 berries from the eventual winner's bucket award.
- Shake It Off removes one trouble card.
- Your Problem Now passes one trouble card to another active player.
- Lucky Patch doubles the player's next numbered Huckleberry contribution to the shared pot.
- Mother Lode adds 25 berries to the shared pot.
- Five buckets are played; highest trip total wins.

## 72-card deck
- Huckleberries: 36 (3/5/7/9/11/13 x5 each, 15 x4, 20 x2)
- Trouble: 21 (Twig x7, Leaf x7, Bug x7)
- Head Home x4
- Evie x4
- Shake It Off x2
- Your Problem Now x2
- Lucky Patch x2
- Mother Lode x1

Single-player and multiplayer use the same deck and rules. Single-player opponents make automated Head Home decisions.
